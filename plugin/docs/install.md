# 安装、升级和卸载

解压发布 ZIP 后运行 BackpackLab.exe。首次安装选择游戏目录与独立的空 Mod 文件夹。安装不要求管理员权限，不修改原版文件。安装器验证支持的 EXE/PCK/DLL 摘要，使用本机游戏资源生成 Mod 和四进程计算组件。

升级使用新版下载包中的启动器，选择同一个 Mod 文件夹。构建在 runtime.next 中进行，成功后才替换 runtime，旧版保留为 runtime.backup-*。安装目录的 .build 含本机生成的缓存，不能对外分发。安装失败查看 install.log；不要将整份缓存或个人数据随问题反馈上传。

之后使用安装目录中的 BackpackLab.exe 或其创建的桌面快捷方式。关闭游戏后，计算进程会自动退出。启动器每次启动检查原版和 Mod 文件完整性，版本变化需等待适配版。

卸载：正常退出游戏，删除桌面“背包实验室”快捷方式及你选择的独立 Mod 安装文件夹即可。Steam 原版文件与存档不受影响。原版用户目录中的 backpack-lab 为保存的曲线和最佳记录，可自行保留或删除；不建议删除整个原版存档目录。

当前版本是未签名的社区预发布软件。仅从本仓库下载，并核对发布的 SHA256SUMS.txt；出现系统安全提示时请自行决定是否运行，本说明不要求关闭安全防护。
