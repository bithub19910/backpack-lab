# 背包实验室 · Backpack Lab

《背包乱斗》战斗模拟 Mod，用于比较摆盘和购买方案的输出、回复与胜率。

**版本：1.0.0** · 支持游戏 **1.1.9b** · Windows 10/11 x64

[下载最新版](https://github.com/bithub19910/backpack-lab/releases/latest)

## 功能

- **战斗预演**：与木桩或上一个对手模拟对战，查看输出、回复曲线及详细统计。
- **摆盘对比**：保存曲线，自动记录当前回合的最佳摆盘。
- **商店预演**：背包有空位时，查看购买商品后的模拟结果。
- **本场胜率**：对当前对战进行 25 次模拟，显示胜率与平均用时。

## 安装

1. 下载 Windows ZIP 并完整解压，双击 `BackpackLab.exe`。
2. 选择 Steam 游戏目录和独立的空 Mod 目录，点击“安装 / 更新”。首次安装需要几分钟。
3. 保持 Steam 登录，退出正在运行的游戏，再通过启动器启动。

需要正版游戏、.NET Framework 4.8 和约 3 GB 可用空间。更新时使用新版启动器执行“安装 / 更新”。

## 使用

在商店选择“木桩”或“上一个对手”，调整摆盘后按 **空格** 或点击“重算”。默认模拟 10 次，统计前 15 秒；时长和次数可在设置中调整。

- **Alt + 8 / Alt + 9**：恢复木桩 / 上个对手模式的最佳摆盘。
- **商店商品按钮**：预演购买效果，需要预留空位。
- **眼睛图标**：显示或隐藏界面。
- **设置 → 清除所有缓存**：计算异常时清理缓存后重算。
