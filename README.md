# Backpack Lab · 背包实验室

Windows《背包乱斗》本地战斗模拟 Mod。支持版本 **1.1.9b**，当前预发布版 **0.2.0**。

在商店选择木桩或上一个对手，按**空格**计算当前摆盘。默认 10 次模拟、15 秒曲线，显示每秒输出与回复，并分别保存两种模式的最佳摆盘。商店商品按钮可在预留空位上模拟购买效果；正式对战结束后提供 25 次模拟胜率。

## 安装和启动

1. 从本仓库 Releases 下载 Windows ZIP，解压到独立文件夹。
2. 双击 **BackpackLab.exe**。选择原版 Steam 游戏目录和空的 Mod 安装目录，点击“安装 / 更新”。
3. 首次安装在本机校验游戏版本、生成资源与计算组件，需要几分钟。保持 Steam 登录，正常退出原版游戏后点击“启动游戏”。
4. 可以创建桌面快捷方式。之后无需终端、CMD 或单独安装 Python；更新时运行新下载包中的启动器。

需要 Windows 10/11 x64、.NET Framework 4.8、正版游戏和约 3 GB 可用空间。启动器不修改 Steam 启动选项，不覆盖游戏 EXE/PCK/DLL。直接从 Steam 启动仍是原版。运行期间最多启用四个独立计算进程。

**下载包不包含游戏本体、解密脚本、物品表、个人存档或对手池。** 安装工具只处理玩家本机指定版本的资源，不绕过购买或 Steam 身份验证。游戏更新后不匹配的文件会被拒绝，不能强行使用旧包。安装产物仅限个人本地使用，请勿重新分发。

## 使用

- 顶部两种模式互斥，点击即计算；空格或“重算”始终计算真实背包，商品预演只由商品按钮触发。
- 木桩为 10000 血空阵容，保留疲劳；15 秒到时停止。对手模式完整算到胜负，曲线与每秒值取选定前 T 秒。
- 主区为输出、回复两张累计曲线；大字每秒值为累计量 / T。
- “恢复最佳摆盘”恢复当前模式的最高“每秒输出＋每秒回复”记录；Alt＋8 对应木桩，Alt＋9 对应上个对手。仅恢复已有物品，不购买、不复制。
- 商品按钮位置对应原版货架，预演使用首个合法空位；没有空位就不计算。预购方案恢复前需要先拥有物品。
- 右上角眼睛收起界面；设置支持透明度、时长、次数。统计按类别、项目和状态变化分级筛选。
- 底部误差是本地多阵容测试的抽样波动估计，**不是模拟器准确度，也不是胜率误差保证**。详见 [测量方法](plugin/docs/precision.md)。

## 开发与验证

项目使用游戏定制 Godot 3.6 引擎执行原生战斗逻辑，自己的 UI/快照/统计/任务池位于 `plugin/godot/`。资源捕获与构建位于 `plugin/packaging/`，Windows 启动器位于 `plugin/windows/`。

参见 [构建说明](plugin/docs/build.md)、[安装与卸载](plugin/docs/install.md)、[第三方许可](THIRD_PARTY_NOTICES.md)。CI 仅运行不依赖游戏的检查；原版引擎联动测试必须由拥有对应游戏版本的维护者在本地运行。
